# Sentiment Analysis

## Overview
This project performs sentiment analysis on Google Play Store reviews using Python and the VADER (Valence Aware Dictionary and Sentiment Reasoner) model from the NLTK library.

## Features
- Analyze Google Play Store reviews
- Classify reviews as Positive, Negative, or Neutral
- Data preprocessing and cleaning
- Sentiment visualization using graphs
- Customer opinion analysis

## Technologies Used
- Python
- Pandas
- NumPy
- NLTK (VADER)
- Matplotlib
- Seaborn
- KaggleHub
- Jupyter Notebook

## Dataset
Google Play Store Reviews Dataset

## Output
The project analyzes customer reviews and visualizes the distribution of sentiments using graphs and charts.
