# Sentiment Analysis

## Overview
This project performs sentiment analysis on product reviews using Python and the VADER (Valence Aware Dictionary and Sentiment Reasoner) model from the NLTK library. It also includes an interactive interface that allows users to enter or upload text and instantly view sentiment predictions, confidence scores, probability distribution, and sentiment history.

## Features
- Analyze product reviews and user-provided text
- Classify text as Positive, Neutral, or Negative
- Display confidence score
- Sentiment probability breakdown
- Interactive sentiment distribution chart
- Explanation of prediction
- Upload `.txt` files for analysis
- Analysis history
- Light/Dark theme
- Responsive and modern UI

## Technologies Used

- Python
- Flask
- Flask-CORS
- HTML5
- CSS3
- JavaScript
- NLTK (VADER)
- Pandas
- NumPy

## Dataset
Google Play Store Reviews Dataset

## Input
The application analyzes product reviews entered manually or uploaded through a text (.txt) file. It can also be tested using sample product reviews.

## Output
The application displays:
- Predicted Sentiment
- Confidence Score
- Sentiment Probability Breakdown
- Sentiment Distribution Chart
- Model Explanation
- Analysis History
